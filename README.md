# 🛡️ Network PCAP Analyzer

A lightweight, real-time network traffic analysis and visualization tool built for initial security triage (detecting DDoS, port scanning, and suspicious outbound/inbound connections). Developed using Python, Scapy, and Plotly Dash.

## 🚀 Features
* **Packet Capture & Parsing:** Inspects TCP, UDP, and ICMP packets from PCAP files or live interfaces.
* **Interactive Dashboard:** Built with Plotly Dash to provide dynamic visual charts of protocol distributions and top active source IPs.
* **Security Triage Support:** Designed to help Security Operations Center (SOC) analysts quickly spot traffic anomalies.

## 🛠️ Tech Stack
* **Language:** Python
* **Packet Manipulation:** Scapy
* **Dashboard & Visualization:** Plotly Dash, HTML/CSS
* **Version Control:** Git & GitHub
